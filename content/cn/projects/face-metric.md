Face Metric 是一个开源的深色主题 Web 应用，用于比较两张人脸图片并给出直观的相似度结果。它面向亲属、兄弟姐妹、亲子或伴侣之间的外貌相似性探索，而不是传统的“是否为同一个人”身份验证。

常见人脸识别系统主要针对身份判定进行优化。Face Metric 采用不同思路：融合多个模型生成的人脸特征向量，通过贴近人类感知的校准曲线计算连续相似度，并使用共同特征标签和自然语言摘要解释结果。

## 核心功能

- **人性化评分：** 将模型相似度转换为更加直观的连续外貌相似度。
- **多模型融合：** 结合 ArcFace 与 Facenet512 特征向量，使比较结果更均衡。
- **可靠的人脸对齐：** 使用 RetinaFace 进行关键点检测和对齐，并提供自动回退方案。
- **特征级解释：** 展示眼部与表情、下颌线、面部轮廓等共同特征。
- **响应式流程：** 桌面端使用并排比较卡片，移动端提供便于触控的纵向操作流程。
- **灵活的图片输入：** 支持拖放上传以及移动设备摄像头拍摄。
- **技术透明度：** 在可折叠的技术区域中展示余弦距离、模型融合和置信度等工程信息。

## 隐私优先

上传的图片仅在当前请求中于内存内处理，不会持久化写入磁盘，因此默认流程不会形成用户照片库。与所有人脸分析工具一样，结果具有概率性，只适合作为外貌相似性的探索参考，不能用于身份证明、生物识别认证或医学结论。

## 架构与技术栈

前端使用 **Next.js 16**、**React 19** 和 **Tailwind CSS**；后端由 **FastAPI** 提供图像分析服务，并结合 **DeepFace**、**TensorFlow** 与 **OpenCV**。RetinaFace 负责人脸检测与对齐，ArcFace 和 Facenet512 则提供融合与校准所需的特征向量。

仓库提供 Docker 部署、命令行快速比较工具，以及覆盖桌面端和移动端流程的 Playwright 端到端测试。Face Metric 采用 MIT 许可证开源，可通过 GitHub 查看、运行和扩展。
