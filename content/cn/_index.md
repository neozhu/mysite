## Clean Architecture Blazor Server

模块化 Blazor Server 企业级应用框架，遵循 Clean Architecture 分层原则并结合 pstack 多智能体协同工作流，助力团队高效构建可维护、可扩展的业务系统。

- .NET 11 与 C# 全栈组件交互
- 内置代码生成器与多数据库支持
- pstack 架构设计与审查 AI 开发流
- 预置 Docker、CI/CD 与 NuGet 模板

## CleanAspire 云原生 PWA 模板

整合 Blazor WebAssembly、Minimal API、PWA 与 .NET 11 + Aspire 技术栈，开箱支持离线缓存与实时推送，快速构建轻量级现代 Web 应用。

- Blazor WASM + Minimal API 架构
- .NET Aspire 云原生可观测支持
- IndexedDB 离线缓存与消息推送
- Microsoft.Kiota 自动生成强类型客户端
