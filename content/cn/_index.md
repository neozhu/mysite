## Clean Architecture Blazor Server

模块化 Blazor Server 企业级应用框架，遵循 Clean Architecture 原则并集成 AI 规范驱动工作流（OpenSpec），助力高效构建可维护、可扩展的业务系统。

- 🧱 基于 .NET 11 与 C# 全栈交互
- 🚀 内置代码生成器与多数据库支持
- 📋 OpenSpec 结构化 AI 变更工作流
- 🐳 预置 CI/CD、Docker 与 NuGet 模板

## CleanAspire 云原生 PWA 模板

整合 Blazor WebAssembly、Minimal API、PWA 与 .NET 11 + Aspire 技术栈，开箱支持离线缓存与实时推送，快速构建轻量级现代 Web 应用。

- ⚡ Blazor WASM + Minimal API & Aspire
- 🌐 IndexedDB 离线缓存与 Web Push
- 🔄 Microsoft.Kiota 自动生成客户端
- 🚀 预置 Docker 与 GitHub Actions
